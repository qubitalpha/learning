# Agent Guidelines for AI Systems Learning Track

## Note-Taking Rules
- **Audience**: Channa only. Notes are for personal recall.
- **Format**: Flat bullet points only (10 to 15 bullets max).
- **Style**: No titles or section headers in note files. Direct, punchy, zero filler words. Keep Channa's exact terminology and links to past projects (`micrograd`, `makemore`).
- **File Location**: All notes go into `notes/<topic>.md`.
- **Source Link**: Video or paper URL must be the first bullet point.

## Workspace Organization
- **Curriculum Tracker**: `README.md` is the source of truth for the curriculum.
- **Notes**: Saved under `notes/`.
- **Projects**: Real code implementations live in sibling directories under `Projects/` (e.g. `../mini-vllm/`).

## Progress Tracking & Next Steps
- Update `README.md` when an item is done by changing `[ ]` to `[x]` and hyperlinking the item to the notes or project.
- Automatically commit and push updates to `origin/main`.
- When asked "What should I learn next?", check `README.md`, find the first uncompleted `- [ ]` item, and present only that next concrete task.
